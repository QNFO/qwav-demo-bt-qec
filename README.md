# BT-Tree QEC: Staircase Redundancy Demo

Interactive demo of the Bruhat-Tits tree as a quantum error-correcting code geometry.

Demonstrates:
- **Staircase redundancy** vs smooth Archimedean codes
- **Ultrametric error confinement** (click to inject errors)
- **Animated tree growth** (watch levels build step by step)
- **Live redundancy curve** comparison

## How to use
1. Select prime p (2, 3, or 5)
2. Adjust tree depth with slider
3. Switch between Tree and Curve views
4. Toggle "Compare Archimedean" to see the smooth vs staircase contrast
5. Toggle "Inject error" and click nodes to see hierarchical error confinement
